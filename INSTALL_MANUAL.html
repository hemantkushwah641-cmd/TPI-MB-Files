TPI Measurement Book

Install manual  ·  Version 2.3.1  ·  Master PC + User PCs

1. What you need

  • Windows 10 or 11 (64-bit)
  • Python 3.12 — Windows installer .exe only. Do not use .tar.xz (that is for Linux).
  • Internet for the first install (pip + Chromium)
  • One shared OneDrive folder, example: OneDrive\TPI-Usage — same path on every PC
  • This zip: tpi_mb_downloader_windows.zip
Do not use the GitHub folder named TPI-MB-Files-main. That package is incomplete. Use this zip only.

2. Remove the old software (both PCs)

  1. Close TPI MB Downloader if it is open.
  2. Open the old folder → double-click UNINSTALL.bat.
  3. Type YES then Enter.
  4. When asked to delete saved IDs, type YES again (clean install).
  5. Delete the old folder. Delete the desktop icon if it is still there.

Do this on the Master PC and on every User PC.

3. Install Python (if not already installed)

  1. Download: python-3.12.10-amd64.exe
  2. Run the .exe.
  3. Tick “Add python.exe to PATH” at the top.
  4. Click Install Now → Finish → restart the PC.

4. Install TPI Measurement Book

  1. Extract this zip to a simple folder, example C:\TPI-MB.
  2. Open tpi_mb_downloader_windows.
  3. Right-click INSTALL.bat → Properties → tick Unblock → OK.
  4. Double-click INSTALL.bat. Wait until it says Install complete.
  5. Desktop icon appears: TPI MB Downloader.
If Windows SmartScreen appears: More info → Run anyway.

5. First run — every PC

  1. Open the desktop icon.
  2. Create the same master password on every PC (8+ characters). Remember it. Do not give it to operators.
  3. When asked, select the same OneDrive folder (example TPI-Usage). This path is locked.
  4. Set Save bills to = your Kautilya E-MB folder.
  5. Click + Add ID and save the portal IDs (3 IDs). Portal passwords stay encrypted.
If someone edits settings.json to change the shared folder, the app restores the locked path. Master tab will show share_tamper.

6. Your PC = Master

  1. Modules / Lock
  2. Select Master — extra tab with every PC / user / version / activity
  3. Enter master password → Save
  4. Open tab 4. Master

This tab shows: computer name, Windows user, software version, Active/Idle, opens / downloads / uploads today, and the activity feed.

7. Other desktops = User

  1. Leave the role as User (default).
  2. They see Download / Upload / Summary only. No Master tab.
  3. They cannot see or change the shared usage folder.

8. Daily use

  1. Click the desktop icon.
  2. When the browser opens: tick CAPTCHA → SIGN IN. Do not close that window.
  3. Download or Upload as required.

10. Uninstall

  1. Close the app.
  2. Double-click UNINSTALL.bat → YES.
  3. YES again to delete saved IDs.
  4. Delete the folder.
